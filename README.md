# Todo App

A simple Todo application built with React and Node.js.

### Developer : Mohan Pramanik

## Features

- Add new tasks
- Mark tasks as completed
- View todo items
- Delete todo items
- Frontend and backend separated

## Tech Stack

### Frontend
- React
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
